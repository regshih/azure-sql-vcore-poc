# Support boundaries

This repository is provided by its contributors under the MIT license, without
a service commitment, production support SLA, or company endorsement.

For reproducible repository bugs, open a sanitized issue with revision, local
tool versions, relevant command using placeholders, expected/actual behavior and
test output with identifiers removed. Do not include raw cloud responses or
customer-specific configuration. Use [SECURITY](SECURITY.md) for sensitive reports.

For Azure service incidents, billing, subscriptions, product limits or account
access, use the appropriate official Azure support channel from the affected
account. Do not post those account details here.

Start troubleshooting with [deployment](docs/deployment-guide.md),
[monitoring](docs/monitoring-guide.md), [spike outcomes](docs/spike-and-throttling-guide.md)
and [serverless tests](docs/serverless-test-guide.md). Unknown production objectives
remain TBD; no repository issue response should be interpreted as production
sizing or availability approval.

Maintainers may request a minimal synthetic reproduction. Do not run intrusive,
load, failover, restore or destructive operations on a system without explicit
authorization.
